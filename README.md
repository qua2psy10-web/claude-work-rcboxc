# RCボックスカルバート設計アプリ

道路土工「カルバート工指針」の考え方に基づく **単室(1連)RCボックスカルバート** の
設計計算ツールです。外部ライブラリに依存しない単一HTMLファイルとして動作します。

## 使い方

**<https://qua2psy10-web.github.io/claude-work-rcboxc/>** をブラウザで開くだけです。

リポジトリ直下の `index.html` を保存してローカルで開いても同じように動きます
(単一ファイルで完結しているためオフライン可、インストール不要)。

左の入力欄を変更すると即座に再計算され、中央に図、右に照査結果が表示されます。
「計算書を印刷」でブラウザの印刷機能からPDF化できます。

開発時は次のとおり。

```sh
npm test        # 計算コアの検証(node:test、30ケース)
npm run build   # src/ を結合して index.html を生成
```

## 機能

| 区分 | 内容 |
| --- | --- |
| 荷重ケース | 載荷位置(上載/側載)×土被り(H1/H2)×地下水(無/有)の組合せを自動生成し、断面力を包絡して照査 |
| 荷重算定 | 躯体自重、鉛直土圧(埋戻し形式の係数 α)、T荷重の分布、静止土圧、外水圧・揚圧力、内水重・内水圧 |
| 構造解析 | 部材軸線による閉合ラーメンを直接剛性法で解析。ハンチによる断面変化を要素分割で表現し、底版は弾性床上の梁として扱う |
| 断面照査 | 許容応力度法(n=15)。軸力を考慮した偏心圧縮として曲げ圧縮・鉄筋引張・平均せん断応力度を照査 |
| 配筋設計 | 必要鉄筋量と最小鉄筋量から、呼び径×ピッチの候補を絞って自動選定。配力鉄筋の目安も提示 |
| 安定検討 | 鉛直支持力、浮上り、水平力の釣合い、底版反力の偏り(全ケースの最悪値) |
| 出力 | 表紙付きの計算書(印刷/PDF)、断面図・荷重図・M/S/N図・反力図、条件のJSON保存/読込 |

## 荷重ケース

実務の設計計算書にならい、次の3軸の組合せでケースを生成します。

| 軸 | 区分 |
| --- | --- |
| 載荷位置 | **上載**(荷重がカルバート直上。頂版に鉛直活荷重が載る) / **側載**(荷重がカルバート側方。背面の上載荷重 Q による側方土圧のみ) |
| 土被り | H1(最小) / H2(最大) |
| 地下水 | 影響なし / 影響あり |

番号は CASE-1 上載・H1・水無、CASE-2 側載・H1・水無、CASE-3 上載・H2・水無、
CASE-4 側載・H2・水無、CASE-5〜8 が同じ並びで地下水ありです。
地下水位を入力しない場合は CASE-1〜4 の4ケース、土被りの最小と最大が等しい場合や
活荷重を考慮しない場合は重複するケースを畳みます。

照査は全ケースの断面力を包絡した最大値で行い、どのケースが支配したかを画面と
計算書の両方に表示します。

## 計算の前提

### 荷重

- **鉛直土圧**: 深さ z の全鉛直応力 σv(z) = γ·min(z,dw) + γsat·max(0, z−dw) に鉛直土圧係数 α を乗じる。
- **活荷重**: 輪荷重を分布角 θ で分散させ、車両の占有幅 W で除して分布圧に置き換える。

  輪分布幅  u = a + 2H·tanθ（進行方向）、v = b + 2H·tanθ（車両直角方向。参考値）
  活荷重    Pl = P(1+i)·β、  Pvl = 2·Pl / W / u

  ここに P は後輪1輪の荷重（T-25 で 0.4×T = 100 kN）、W は車両の占有幅（既定 2.75 m）、
  β は断面力低減係数（既定 1.0）。衝撃係数 i は土被り h に応じ、h ≤ 1.5 で 0.5、
  1.5 < h < 6.5 で 0.65 − 0.1h、h ≥ 6.5 で 0（入力欄で直接指定も可能）。

- **側方土圧**: σh(z) = K·(σv(z) − u(z)) + u(z)。活荷重ぶんは K·α·qL を等分布で加算。
  地下水位を挟む場合は側壁の分割にその位置を含め、折れ点を再現する。
- **底版反力**: 荷重として与えず、鉛直地盤反力係数 kv の分布バネで受ける。
  これにより反力分布が解析結果として得られ、鉛直方向の釣合いが常に成立する。

### 断面照査

単鉄筋長方形断面(奥行 1000mm)、ヤング係数比 n = 15。軸力を考慮した偏心圧縮として解く。

- 偏位量 e = M/N、鉄筋位置 c = d − T/2、軸力を考慮した曲げ Ms = M + N·c
- 中立軸 x: N·x³ − 3(N·T/2 − M)·x² + 6n·As/b·Ms·(x − d) = 0 を二分法で解く
- σc = 2Ms/(b·x·(d − x/3))、σs = n·σc·(d − x)/x、τm = S/(b·j·d)
- N = 0 のとき中立軸は b·x²/2 = n·As·(d − x) に、σc は 2M/(b·x·j·d) に退化し、
  軸力を無視した従来式と一致する。
- 曲げの照査断面は各部材の支間中央と両端(ハンチ端)。引張面ごとに包絡する。
- **せん断の照査位置(τ点)は支点前面から T/2**。その位置がハンチ内にある場合、
  部材断面の高さはハンチ高さ C' の 1/3 まで大きくとる。

  h' = T + C'/3

  ハンチが T/2 以下の場合は照査位置がハンチ端の外に出るため C' = 0 となり、
  基本厚 T のままとなる。
- 許容せん断応力度に道路橋示方書の有効高・引張鉄筋比による補正を行う場合は、
  入力欄の補正係数 ce・cpt に値を入力する(既定値は 1.0、すなわち補正なし)。

### 検証

計算コアには次の検証を回帰テストとして組み込んでいます。

- 骨組ソルバを単純梁・両端固定梁・片持ち梁・L形骨組・三角形分布荷重・弾性床の
  解析解と照合(いずれも 1e-6 以内で一致)
- 荷重算定値の手計算との照合(土圧・上載/側載の活荷重・水圧)。
  活荷重は参照した実務の計算書と同条件で u・v・Pl・Pvl が一致することを確認
- せん断の照査位置とハンチによる h' = T + C'/3、および τ点の左右対称性
- 鉛直方向の釣合い(載荷重の合計 = 底版バネ反力の合計)を6条件 × 全ケースで確認
- 隅角部で接合する2部材の曲げモーメントの連続性
- 左右対称な条件における断面力の対称性
- 荷重ケースの生成順序、重複ケースの畳み込み、旧形式入力の後方互換
- 包絡値が全ケースの最大値と一致し、支配CASEの記録が整合すること
- Ms = M + N·c の恒等式
- 標準ケース(内空2.0×2.0m、部材厚300mm、土被り1.0〜3.0m)の回帰値

## 計算書

「計算書を印刷」でブラウザの印刷機能から出力します。章立ては次のとおりです。

```
表紙            工事情報・内空寸法・土被り・形状図・総合判定
1 設計条件      一般条件 / 単位体積重量 / 土圧係数 / 活荷重 / 衝撃係数 /
                鉄筋かぶり / 許容応力度 / 標準断面図 / 荷重の組合せ
2 断面力計算    ケースごとに 設計荷重 → 構造解析 → 各部材の断面力
3 断面力集計表  各ケースからの最大値抽出(M・N・e・c・Ms・支配CASE)
4 必要鉄筋量
5 配筋及び実応力度
6 せん断力に対する検討(ケース別の一覧と最大値抽出)
7 安定・基礎の検討
8 確認事項
```

工事名・工区名・設計者・作成日・製品No. は画面の「工事情報」から入力でき、
表紙と各ページのヘッダに反映されます。ページ番号はブラウザの印刷設定の
ヘッダー/フッターで付けてください。

## 構成

```
src/core/    DOMに依存しない計算モジュール
  frame.js      直接剛性法による平面骨組ソルバ
  geometry.js   部材軸線モデルとハンチによる断面変化、要素分割
  loads.js      荷重の算定
  analyze.js    解析の実行と照査断面の断面力抽出
  rc.js         許容応力度法の断面照査
  rebar.js      配筋の自動選定
  stability.js  安定・基礎の検討
  design.js     全体を束ねるエントリと既定条件
  units.js      材料定数・許容応力度テーブル
src/ui/      画面描画と入出力
test/        node:test による検証
build.js     単一HTMLへの結合スクリプト
index.html   ビルド成果物。GitHub Pages が配信する公開物
.nojekyll    Pages で Jekyll の処理を行わせないための空ファイル
```

`index.html` と `src/index.html` は役割が異なります。
**直下の `index.html` はビルド成果物**(全モジュールとCSSをインライン展開した配布物)で、
直接編集しても `npm run build` で上書きされます。編集するのは `src/index.html`
(開発用エントリ、`type="module"` で `src/` を読む)のほうです。

## 適用範囲と制限

- 対象は **単室ボックスカルバート1連**、**許容応力度法** のみです。
- 多連ボックス、斜角、縦方向の検討、限界状態設計法は対象外です。
- 土被りが 0.5m 未満の場合、活荷重を分布荷重に置換する扱いは適用範囲外です
  (輪荷重の直接載荷による別途検討が必要。画面に警告を表示します)。
- 部材軸線モデルのため隅角部の形状を厳密には表せません。自重は実形状から求めた
  コンクリート断面積と総量が一致するよう補正しています。
- 本ツールの結果は設計の一次検討を目的としたものです。実施設計にあたっては、
  必ず有資格者による確認を行ってください。
