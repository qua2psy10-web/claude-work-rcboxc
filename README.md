# RCボックスカルバート設計アプリ

道路土工「カルバート工指針」に準拠した **単室(1連)RCボックスカルバート** の設計計算ツールです。
外部ライブラリに依存しない単一HTMLファイルとして動作します。

## 機能

- 荷重算定(鉛直土圧・側方土圧・活荷重T-25・自重・水圧/浮力・底版反力)
- 閉合ラーメンの骨組解析(直接剛性法、弾性床上の底版としてモデル化)
- 断面力(M・S・N)の算出と図化
- 許容応力度法による曲げ・せん断照査
- 必要鉄筋量からの配筋自動選定
- 安定・基礎検討(鉛直支持力・浮上り・水平力の釣合い)
- 計算書の印刷出力、条件のJSON保存/読込

## 使い方

`dist/index.html` をブラウザで開くだけです(オフライン可)。

開発時は次のとおり。

```sh
npm test        # 計算コアの検証(node:test)
npm run build   # src/ を結合して dist/index.html を生成
```

## 構成

- `src/core/` … DOMに依存しない純粋な計算モジュール(ソルバ・荷重・照査)
- `src/ui/` … 画面描画と入出力
- `test/` … 解析解との照合および設計例の回帰テスト
- `build.js` … 単一HTMLへの結合スクリプト

## 適用範囲と制限

- 対象は **単室ボックスカルバート1連**、**許容応力度法** のみです。
- 多連ボックス、斜角、縦方向の検討、限界状態設計法は対象外です。
- 本ツールの結果は設計の一次検討を目的としたものです。実施設計にあたっては、
  必ず有資格者による確認を行ってください。
