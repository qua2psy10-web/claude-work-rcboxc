# RCボックスカルバート設計アプリ

道路土工「カルバート工指針」の考え方に基づく **単室(1連)RCボックスカルバート** の
設計計算ツールです。外部ライブラリに依存しない単一HTMLファイルとして動作します。

## 使い方

`dist/index.html` をブラウザで開くだけです(オフライン可、インストール不要)。
左の入力欄を変更すると即座に再計算され、中央に図、右に照査結果が表示されます。
「計算書を印刷」でブラウザの印刷機能からPDF化できます。

開発時は次のとおり。

```sh
npm test        # 計算コアの検証(node:test、30ケース)
npm run build   # src/ を結合して dist/index.html を生成
```

## 機能

| 区分 | 内容 |
| --- | --- |
| 荷重算定 | 躯体自重、鉛直土圧(埋戻し形式の係数 α)、T-25活荷重の分布、静止土圧、外水圧・揚圧力、内水重・内水圧 |
| 構造解析 | 部材軸線による閉合ラーメンを直接剛性法で解析。ハンチによる断面変化を要素分割で表現し、底版は弾性床上の梁として扱う |
| 断面照査 | 許容応力度法(n=15)による曲げ圧縮・鉄筋引張・平均せん断応力度の照査 |
| 配筋設計 | 必要鉄筋量と最小鉄筋量から、呼び径×ピッチの候補を絞って自動選定。配力鉄筋の目安も提示 |
| 安定検討 | 鉛直支持力、浮上り、水平力の釣合い、底版反力の偏り |
| 出力 | 断面図・荷重図・M/S/N図・反力図、印刷用計算書、条件のJSON保存/読込 |

## 計算の前提

### 荷重

- **鉛直土圧**: 深さ z の全鉛直応力 σv(z) = γ·min(z,dw) + γsat·max(0, z−dw) に鉛直土圧係数 α を乗じる。
- **活荷重**: 後輪1輪 P を接地面 a×b から分布角 θ で分散させ、1後軸の左右2輪を合成する。

  q = 2P(1+i) / (La · Lb)、La = a + 2h·tanθ、Lb は左右輪の分布が重なる場合 輪間隔 + 1輪分の幅、
  重ならない場合 2輪分の幅。衝撃係数 i は土被り h に応じ、h ≤ 1.5 で 0.5、
  1.5 < h < 6.5 で 0.65 − 0.1h、h ≥ 6.5 で 0。

- **側方土圧**: σh(z) = K·(σv(z) − u(z)) + u(z)。活荷重ぶんは K·α·qL を等分布で加算。
  地下水位を挟む場合は側壁の分割にその位置を含め、折れ点を再現する。
- **底版反力**: 荷重として与えず、鉛直地盤反力係数 kv の分布バネで受ける。
  これにより反力分布が解析結果として得られ、鉛直方向の釣合いが常に成立する。

### 断面照査

単鉄筋長方形断面(奥行 1000mm)、ヤング係数比 n = 15。

- 中立軸 x: b·x²/2 = n·As·(d − x)、j = 1 − x/(3d)
- σc = 2M/(b·x·j·d) + N/(b·h)、σs = M/(As·j·d)、τm = S/(b·j·d)
- 照査断面は各部材の支間中央と両端(ハンチ端)の計12断面。
- 軸圧縮力は N/(b·h) をコンクリート圧縮応力度に加算する形で考慮し、
  引張鉄筋側には安全側となるよう考慮していない。
- 許容せん断応力度に道路橋示方書の有効高・引張鉄筋比による補正を行う場合は、
  入力欄の補正係数 ce・cpt に値を入力する(既定値は 1.0、すなわち補正なし)。

### 検証

計算コアには次の検証を回帰テストとして組み込んでいます。

- 骨組ソルバを単純梁・両端固定梁・片持ち梁・L形骨組・三角形分布荷重・弾性床の
  解析解と照合(いずれも 1e-6 以内で一致)
- 荷重算定値の手計算との照合(土圧・活荷重・水圧)
- 鉛直方向の釣合い(載荷重の合計 = 底版バネ反力の合計)を6つの荷重条件で確認
- 隅角部で接合する2部材の曲げモーメントの連続性
- 左右対称な条件における断面力の対称性
- 標準ケース(内空2.0×2.0m、部材厚300mm、土被り1.0m)の回帰値

## 構成

```
src/core/    DOMに依存しない計算モジュール
  frame.js      直接剛性法による平面骨組ソルバ
  geometry.js   部材軸線モデルとハンチによる断面変化、要素分割
  loads.js      荷重の算定
  analyze.js    解析の実行と照査断面の断面力抽出
  rc.js         許容応力度法の断面照査
  rebar.js      配筋の自動選定
  stability.js  安定・基礎の検討
  design.js     全体を束ねるエントリと既定条件
  units.js      材料定数・許容応力度テーブル
src/ui/      画面描画と入出力
test/        node:test による検証
build.js     単一HTMLへの結合スクリプト
dist/        配布物(index.html)
```

## 適用範囲と制限

- 対象は **単室ボックスカルバート1連**、**許容応力度法** のみです。
- 多連ボックス、斜角、縦方向の検討、限界状態設計法は対象外です。
- 土被りが 0.5m 未満の場合、活荷重を分布荷重に置換する扱いは適用範囲外です
  (輪荷重の直接載荷による別途検討が必要。画面に警告を表示します)。
- 部材軸線モデルのため隅角部の形状を厳密には表せません。自重は実形状から求めた
  コンクリート断面積と総量が一致するよう補正しています。
- 本ツールの結果は設計の一次検討を目的としたものです。実施設計にあたっては、
  必ず有資格者による確認を行ってください。
